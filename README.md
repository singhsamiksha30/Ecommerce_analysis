# Ecommerce_analysis
E-Commerce Sales Analysis

An end-to-end E-Commerce Sales Analysis project using SQL, Python, and Power BI to analyze sales performance, revenue trends, product categories, and regional performance.

Project Overview

This project analyzes an e-commerce sales dataset to identify important business insights and present them through an interactive Power BI dashboard.

The project covers the complete data analytics workflow:

Data → SQL Analysis → Python Analysis → Power BI Dashboard → Business Insights

Objectives

- Analyze overall sales and revenue performance
- Identify the best-performing product categories
- Analyze sales across different regions
- Identify monthly sales trends
- Analyze product-level performance
- Create an interactive Power BI dashboard
- Generate business insights from the data

Tools & Technologies

- MySQL — Data storage, cleaning and SQL analysis
- Python — Data analysis and visualization
- Pandas — Data manipulation
- NumPy — Numerical analysis
- Matplotlib — Data visualization
- Power BI — Interactive dashboard and reporting
- GitHub — Project documentation and version control
